# A Preset Model for Updating Layouts

Case study: redesigning a template preset selector for a B2B presentation software add-in.

## What This Is

One click, no guesswork. The feature updates slides from an outdated corporate design to a new one, automatically adjusting layouts, fonts and colors. This case study documents the redesign of the preset-selection dialog, from a two-option choice with no differentiation to a three-tile model with a hidden expander for edge cases.

## My Role

Associate UI Designer. Developed the terminology architecture through four iterations, derived the collapse pattern from DeepL as a UI reference, made the technical decision to use a ListBox instead of RadioButtons, wrote the German UI copy, and carried out the XAML implementation in coordination with an international partner company.
